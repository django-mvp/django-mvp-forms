# Modifiers

A modifier changes a field that already exists. It adds no field of its own:
the same input comes out smaller, in another colour, locked, or with something
attached to its edge.

Most modifiers are stated once for the whole form in the helper's `FormChoices`,
and overridden for one field with a `Choice`.

```{toctree}

size-colour-variant
state
floating-labels
attached-text-and-buttons
inline-field
```
